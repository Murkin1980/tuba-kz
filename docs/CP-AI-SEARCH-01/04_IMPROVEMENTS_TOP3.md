# 04 — ≤3 улучшения с наибольшим влиянием на заявки

> Принцип MPE EXTEND_EXISTING: переиспользовать существующий статический сайт, не создавать новые сервисы/CMS/мониторинг. Каждое улучшение — малая правка существующего файла, без новых цен/скидок/брендов без подтверждения владельца. После `APPROVED` — отдельный PR + `check-google-ads-readiness.ps1` + `node --check`.

## Как выбирались
Критерии: влияние на **qualified inbound** (не пустые клики), effort <1 день, измеримость через 14-дневный GSC/матрицу, отсутствие выдуманных claims, совместимость с Google Ads.

Отклонено: новый блог/CMS, платный AI-мониторинг (Semrush/Ahrefs), генерация отзывов, установка пикселей без согласия — всё это deep-change / HOLD.

### 1) Доверие и GEO-точность: обогатить `LocalBusiness` schema (высший приоритет)

**Проблема сейчас:**
- В `index.html` JSON-LD нет `geo`, `openingHours`, `hasMap`, `priceRange`. AI Overviews и локальный пак любят точный `geo` + часы + карту; без них TUBA-мебель рискует проиграть SAF Mebel/MebelGuru у которых эти поля есть. Адрес “ул. Бенберина, 18” без координат — низкая уверенность модели.

**Что делать (только после подтверждения владельца):**
- В существующий `@graph[0]` добавить (пример, координаты уточнить у владельца / 2GIS):
```json
"geo": { "@type": "GeoCoordinates", "latitude": "43.23XX", "longitude": "76.90XX" },
"hasMap": "https://2gis.kz/almaty/search/%D0%91%D0%B5%D0%BD%D0%B1%D0%B5%D1%80%D0%B8%D0%BD%D0%B0%2018",
"priceRange": "₸₸",
"areaServed": { "@type": "City", "name": "Алматы" },
"openingHoursSpecification": { "@type": "OpeningHoursSpecification", "dayOfWeek": ["Monday","Tuesday","Wednesday","Thursday","Friday","Saturday"], "opens": "10:00", "closes": "19:00" }
```
- Добавить `inLanguage: ["ru-KZ","kk-KZ"]` если будет казахский параграф (см. #3).
- Синхронизировать `telephone`, `address`, `sameAs` с footer (уже совпадают — оставить).

**Почему это #1 по лидам:**
- Повышает шанс попасть в локальный пак “мебель на заказ рядом” и получить AI-цитату с картой/телефоном (именно такие блоки дают клики с намерением, а не просто показы).
- Требует 5 строк JSON, 0 новых зависимостей, 100% соответствие AGENTS.md (address — claim requiring confirmation, поэтому нужен `APPROVED`).

**Как измерить:** GSC Pages + Countries + появление `geo`-rich result в проверке Schema Validator; матрица — рост CITATION для “шкафы на заказ Алматы рядом”.

**Риски:** неверные координаты/часы = misleading claim → блокировка. Поэтому только с подтверждением.

### 2) Свежесть и crawl-бюджет: обновить `sitemap.xml` + задокументировать robots-решение

**Проблема сейчас:**
- `lastmod: 2026-06-13` → **141 день stale** при `changefreq: weekly`. Google считает такие sitemap менее свежими; AI freshness — фактор цитирования.
- Нет `<image:image>` для 12 фото (hero + 6 проектов × 1–2 ракурса) — упускается Google Images + AI multimodal grounding.
- Live `robots.txt` (Cloudflare) блокирует `GPTBot / ClaudeBot / Google-Extended` (Disallow) — это **снижает цитируемость в ChatGPT/Claude**, но сохраняет Google Search. Владелец должен сознательно выбрать.

**Что делать:**
- Обновить `sitemap.xml` на дату деплоя (например, `2026-11-05`) и добавить image entries:
```xml
<url>
  <loc>https://www.tuba.kz/</loc><lastmod>2026-11-05</lastmod><changefreq>weekly</changefreq><priority>1.0</priority>
  <image:image><image:loc>https://www.tuba.kz/assets/tuba-hero-wide.jpg</image:loc><image:caption>Мебель на заказ TUBA в Алматы</image:caption></image:image>
  <!-- + 11 image entries для kitchen/wardrobe/... -->
</url>
```
- Оставить текущие 2 URL (home, privacy) — не добавлять выдуманных разделов.
- В `docs/CP-AI-SEARCH-01/EVIDENCE.md` зафиксировать решение по Cloudflare Managed Content: **Option A** (текущий) — держать блок обучения (`ai-train=no`, `GPTBot Disallow`) если приоритет — защита контента; **Option B** — разблокировать `GPTBot`/`ClaudeBot` если приоритет — цитируемость в ChatGPT/Claude. Любой выбор — 1 переключатель в Cloudflare Dashboard, без изменения кода.

**Почему #2:**
- Свежий sitemap + images — самый дешёвый способ поднять crawl-бюджет для 2-страничного сайта; конкуренты (TheFive, MebelGuru) используют image sitemap.
- Ясность по robots предотвращает “тихий” AI-блок, который обнуляет усилия по GEO.

**Как измерить:** дата `lastmod` в GSC Sitemaps → `Success`, количество просканированных изображений; через 14 дней — топ-5 стабильность.

**Риски:** нет; не меняет видимый контент, не ломает Ads.

### 3) Казахский intent: добавить `kk-KZ` сигнал без нового сайта

**Проблема сейчас:**
- На сайте `lang="ru"`, `hreflang` только `ru-KZ`. Тест показал **0/6** каз. запросов с TUBA (все `NO`). При этом в Алматы ~30% поиска — на казахском (“жиһаз тапсырыс”, “ас үй жиһазы”).
- Нет ни одного вхождения “жиһаз” в видимом тексте → модели не могут процитировать на каз. запросе (ghost citation невозможен).

**Что делать (минимально, без CMS):**
- Добавить в `<head>`:
```html
<link rel="alternate" hreflang="kk-KZ" href="https://www.tuba.kz/#kk">
<link rel="alternate" hreflang="x-default" href="https://www.tuba.kz/">
```
- Добавить 1 фактический абзац на казахском над footer (reuse существующего RU-текста, перевод проверен владельцем), например:
> “TUBA — Алматыда тапсырыс бойынша жиһаз. Ас үй, шкаф, гардероб — жеке өлшем, 3D-жоба, келісімшарт бойынша өндіру және құрастыру. Бағасы, мерзімі және кепілдігі келісімшартта бекітіледі.”
- Добавить `id="kk"` якорь; не менять форму/consent.
- Обновить JSON-LD `inLanguage`: `["ru","kk"]`.

**Почему #3:**
- Открывает 6/20 запросов (30% матрицы) с near-zero effort; без этого казахский AI surface остаётся закрыт.
- Не создаёт новую страницу — 1 anchor + 1 абзац, 100% фактический (цитирует уже опубликованные рус. условия договора).

**Как измерить:** через 14 дней — хотя бы 1/6 KK `NO` → `CITATION` или `MENTION` в Google; иначе — усилить.

**Риски:** некачественный машинный перевод = misleading → только с владельцем-носителем; поэтому #3, а не #1.

## Что НЕ делать (явно отклонено)

- Не генерировать отзывы/`aggregateRating` без реальных отзывов (нарушение `risky-claims`).
- Не публиковать “бесплатный замер”, “гарантия X лет”, “немецкое оборудование”, “Blum” (требует доказательств).
- Не покупать SaaS для AI-мониторинга — сначала manual 14-дневный сплит (simplicity-first: `HOLD`).
- Не менять `AW-18220207101`, canonical, consent, WhatsApp-логику.
- Не делать автопубликацию/деплой — только после `APPROVED`.
