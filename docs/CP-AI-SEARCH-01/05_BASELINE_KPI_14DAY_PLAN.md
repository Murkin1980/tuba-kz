```
Интерпретация: correlation, not causation — сезонность, рандом, правки.
Next action: если Δ CITATION ≥2 и лиды ≥1 → подать на внедрение #1–#3; иначе HOLD.
```

### 3.4 Статистика: низкий объём, высокая вариабельность

- При 20 запросах стандартная ошибка для доли 5% ≈ 4.9% → **±1 позиция = шум**.
- При ~5 лидах в месяц дисперсия Пуассона σ≈√5 → **±2 лида = шум**.
- Поэтому **PASS = “метод воспроизведён, данные не выдуманы”, а не “выросли лиды”**. Causal proof невозможен без GSC/GA4.

## 5. PASS / PARTIAL / BLOCKED — критерии

| Вердикт | Условие |
|---------|---------|
| **PASS** | Аудит датирован + 20-матрица воспроизведена + GSC статус честно зафиксирован (DATA_UNAVAILABLE) + ≤3 улучшения предложены + 14-дневный план с KPI + evidence в репо. Даже если CITATION остаётся 1/20 — это PASS (методология). |
| **PARTIAL** | ≥50% покрытия, но 1 из блоков missing (например, live robots не проверен из-за TLS) — но в нашем кейсе всё снято → не применяется. |
| **BLOCKED** | Нет доступа к сайту (404) или владелец запретил даже read-only — но сайт 200 → не применяется. |

**Фактический вердикт 2026-11-01: PASS (по методологии) + PARTIAL (по бизнес-видимости 1/20).**

## 7. Риски и disclosure

- Сезонность мебели (осень) может дать +лиды без связи с SEO.
- Бренд-коллизия “Tuba” (ЖК/ресторан Актау, кондитерский Усть-Каменогорск) размывает entity — без `hasMap/geo` AI может путать.
- AI Overviews появляются только когда Google считает полезным — отсутствие AI блока ≠ failure.
- GSC generative AI impressions могут остаться 0 даже при хорошем GEO (низкий объём).

Всё это — не failure метода, а honest limits.
